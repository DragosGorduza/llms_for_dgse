# runs/

Output of experiments. Everything here except this file is gitignored.

Layout: `runs/<experiment_id>/<run_id>/` with

- `config.resolved.yaml` : fully resolved config for this cell
- `manifest.json` : config hash, versions, timestamps, status, what was modified and how
- `llm_calls.jsonl` : one `LLMCall` per line (prompt, response, parsed, cache hit); no keys
- `shock_paths.parquet` : the path injected into each model variable
- `trajectories.parquet` : long format `(scenario, variable, t, value)` for baseline, shocked and irf; when the scenario mixes classic and LLM shocks also `classic`, `llm`, `irf_classic`, `irf_llm`, `irf_interaction`
- `metrics.json` : peak, time of peak, cumulative effect, half-life per variable (of the combined response)
- `metrics_arms.json` : only for classic + LLM scenarios; the same metrics for the classic, LLM, combined and interaction responses
- `report.md`, `figures/` : generated by `dgse-llm report`

`runs/<experiment_id>/index.parquet` lists every cell of a sweep with its status.
